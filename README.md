# AI Agent Media Lab

このプロジェクトは、AIエージェント検証メディア / X運用実験 / 本人アカウント運用の戦略と実行ログを管理するためのローカル正本です。

詳細な戦略・仮説・投稿案は、ChatGPTとの議論で決まった内容を人間が追記していきます。

## 主要ファイル

- `strategy.md`: 戦略の正本
- `agents.md`: サブエージェント設計
- `research/accounts.csv`: 参考アカウント一覧
- `research/posts.csv`: 参考投稿分析
- `content/media-account.md`: メディアアカウント用の情報
- `content/personal-account.md`: 本人アカウント用の情報
- `logs/daily.md`: 日次ログ
- `outputs/next-actions.md`: 次にやること
